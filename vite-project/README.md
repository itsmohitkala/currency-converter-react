# 💱 Currency Converter React

A responsive currency converter built with **React** and **Vite** that allows users to convert between multiple currencies using real-time exchange rates.

---

## 🚀 Features

- Convert between multiple currencies
- Real-time exchange rate data
- Fast and lightweight (Vite)
- Responsive UI
- Clean and simple design

---

## 🛠️ Tech Stack

- **React**
- **Vite**
- **JavaScript (ES6+)**
- **CSS**
- **API for exchange rates**

---

## 📦 Installation & Setup

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/itsmohitkala/currency-converter-react.git

# Navigate to the project folder
cd currency-converter-react

# Install dependencies
npm install

# Start the development server
npm run dev
